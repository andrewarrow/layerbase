METHOD AND REPRODUCTION
Same Node.js client and Hrana v2 JSON HTTPS/1.1 transport with pooled
TCP/TLS connections, one SQL statement and stream close per request, no
retries, two-second excluded warmup, eight-second ramp stages, and
20-second confirmations. End-to-end latencies include network and queueing.
First run tested reads through 256 and stopped on HTTP 429. The second
completed every workload through a maximum concurrency of 128. Two final
read-only runs checked 224 (rare HTTP 429s) and 192 (zero errors).
Each run was bounded to 600 seconds, 250,000 requests, and 1,000,000
attempted inserted rows; no continuous load or monitor remains running.

Full workload run:
  node benchmarks/run.mjs --provider=turso --reuse --max-concurrency=128
Focused read run:
  node benchmarks/run.mjs --provider=turso --reuse --max-concurrency=192 --concurrency=192 --families=point_read
